# UI Acceptance Checklist — Commercially-style Reference

Use this checklist before marking any frontend step as complete.

## Required
- [ ] Light neutral background used
- [ ] White rounded cards used
- [ ] Green is the main accent color
- [ ] No blue or pink is used as the main brand color
- [ ] Sidebar is rounded and visually close to the reference style
- [ ] Top search and profile area exist where relevant
- [ ] KPI cards follow the approved style
- [ ] Tables use soft gray headers and clean spacing
- [ ] Buttons and pills are rounded
- [ ] Typography is clean, modern, and readable
- [ ] Layout feels premium and ERP-like
- [ ] Product branding updated to Adaptive Call Center Intelligence
- [ ] UI screenshots added to the report
- [ ] Any deviation from the reference explained
