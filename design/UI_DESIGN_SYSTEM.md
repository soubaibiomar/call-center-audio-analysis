# Project 28 UI Design System — Approved “Commercially-style” Reference

## Approved UI direction
Use the uploaded reference image `APPROVED_COMMMERCIALLY_STYLE_REFERENCE.png` as the **primary UI direction** for the whole product.
The goal is **not to copy the brand** from the reference, but to reproduce the same overall product feel:
- clean enterprise SaaS / ERP dashboard
- soft light-gray background
- rounded white cards
- subtle borders and shadows
- green as the primary accent color
- black / charcoal text for hierarchy
- minimal visual noise
- generous whitespace
- compact iconography
- friendly, polished, high-end admin UX

## Visual character
- **Overall feel:** premium, modern, calm, structured, approachable
- **Primary accent:** green only
- **Avoid:** blue primary themes, pink themes, glossy neon effects, dark dashboards, excessive gradients
- **Interaction style:** quiet, business-focused, highly readable

## Core palette
- App background: very light neutral gray `#F6F6F3` to `#F3F4F1`
- Card background: white `#FFFFFF`
- Sidebar background: white or very light gray
- Primary green: medium fresh green around `#9BE15D` / `#98D85B`
- Dark green: `#1D5B49` / `#1F5C48`
- Text primary: near-black `#121212`
- Text secondary: muted gray `#8A8A8A`
- Divider / border: `#ECECE8`
- Positive: green family
- Warning: soft amber / orange
- Negative: soft red

## Layout rules
1. Left rounded vertical sidebar with grouped navigation sections.
2. Top bar with search, notifications, and profile.
3. Large welcome / overview heading area.
4. Rounded KPI cards with icon, metric, comparison text.
5. Charts inside white cards with lots of breathing room.
6. Tables with soft gray headers and pill-style statuses.
7. Rounded filter buttons and dropdowns.
8. CTA buttons should be green and rounded.
9. Each page should feel like part of one coherent design system.

## Product branding guidance
The product name remains **Adaptive Call Center Intelligence**.
Replace the reference brand name with project branding, but preserve the same visual quality and composition principles.

## Screens that must follow this design
- Dashboard overview
- Calls list
- Live monitoring
- Post-call analysis
- Transcript review and correction
- Emotion analytics
- Coaching and agent performance
- Knowledge base / RAG
- Model lab / training
- Users and teams
- Settings

## Required design behaviors
- Responsive desktop-first layout
- Consistent border radius (large rounded cards)
- Consistent spacing scale
- Reusable design tokens
- Reusable card, table, pill, stat, filter, and chart components
- Accessibility-aware contrast and readable typography

## What every implementation report must include
For every frontend-related step, include:
1. Screenshot(s)
2. Which parts match the approved reference
3. Which parts intentionally differ
4. Color tokens used
5. Components created or reused
6. Accessibility checks performed
7. Remaining UI gaps
